- **Decisions — supported projection and occupancy:** checked the pinned [V2 context endpoint](https://github.com/anomalyco/opencode/blob/v2.0.23/packages/protocol/src/groups/session.ts), which returns `data: PublicSessionMessage[]`, with no authoritative occupancy or token count. Decode that array with the existing tagged-entry projection and render its supported entries using existing chat/context components. Unknown kinds are skipped, consistent with history. Show **Occupancy unknown** for V2, including an empty projection or a disconnected selected session; never estimate from text, sum historical tokens, or reuse the last reply's usage with a model limit. Historical totals in Insights and existing V1 behavior remain unchanged. Reading active context does not request compaction; admission remains ticket 17.
- **Decisions — scope and refresh:** the pinned read accepts the session ID and no workspace-location query. Like other session reads, `/api/session/{sessionID}/context` follows the session's own server location, without overriding it with the workspace picker. Actor binding revisions, connection identity/project revisions, and the selected-session generation reject stale successes and errors. The sheet owns its loading enum, disclosure state and request token; it reloads on selected-session/model/location changes, canonical history recovery and explicit Refresh/pull-to-refresh. An old snapshot is hidden immediately when its scope changes. Bare HTTP 404/405/501 means unavailable; structured session errors, authentication errors, network failures and malformed responses remain retryable failures rather than history fallbacks.
